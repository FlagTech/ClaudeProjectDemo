# Focus Board 產品需求文件

## 1. 專案概述

Focus Board 是一個使用 HTML、CSS 與 JavaScript 製作的輕量待辦事項網頁。

使用者可以新增工作項目、標記完成、刪除項目，並查看目前的工作完成情況。所有資料儲存在瀏覽器的 `localStorage`，重新整理或關閉瀏覽器後仍可保留。

本專案將作為 Claude Code 專案遷移至 OpenCode 的教學範例。

Claude Code 階段只需要完成基礎版本，部分功能會刻意保留給 OpenCode 接手實作。

---

## 2. 專案目標

本專案需要達成以下目標：

* 建立一個不依賴後端服務的待辦事項工具。
* 使用純 HTML、CSS 與 JavaScript 實作。
* 不需要安裝套件即可執行。
* 專案結構清楚，適合由不同 Coding Agent 接手。
* 基礎版本可正常使用，但保留明確的後續開發需求。

---

## 3. 技術限制

專案必須遵守以下限制：

* 使用 HTML5、CSS3 與原生 JavaScript。
* 不使用 React、Vue、Svelte 或其他前端框架。
* 不使用 npm、Vite、Webpack 或其他建置工具。
* 不使用外部 API。
* 不使用外部資料庫。
* 不使用 CSS Framework。
* 不需要使用者登入。
* 資料必須儲存在瀏覽器的 `localStorage`。
* HTML、CSS 與 JavaScript 必須分開存放。

## 5. 使用者情境

### 5.1 新增工作項目

使用者輸入工作內容並送出後，系統應新增一筆待辦事項。

### 5.2 查看工作項目

使用者開啟頁面時，可以看到目前所有尚未刪除的工作項目。

### 5.3 標記工作完成

使用者可以將一筆工作標記為完成，也可以再次操作將其恢復為未完成。

### 5.4 刪除工作項目

使用者可以刪除不再需要的工作項目。

### 5.5 保留資料

使用者重新整理頁面或重新開啟瀏覽器後，原本的工作項目與完成狀態仍應保留。

### 5.6 查看工作統計

使用者可以看到：

* 全部項目數量
* 尚未完成的項目數量
* 已完成的項目數量

## 6. Claude Code 階段功能範圍

Claude Code 需要完成以下功能。

### 6.1 新增待辦事項

頁面應提供：

* 文字輸入欄位
* 新增按鈕

使用者可以透過以下方式新增項目：

* 點擊新增按鈕
* 在輸入欄位按下 Enter

新增成功後：

* 新項目顯示在清單中
* 輸入欄位清空
* 資料寫入 `localStorage`

空白內容不得新增。

項目前後的多餘空白應自動移除。

### 6.2 顯示待辦清單

每筆待辦事項應顯示：

* 完成狀態控制元件
* 工作內容
* 刪除按鈕

可以使用 checkbox、按鈕或其他容易理解的控制方式。

### 6.3 切換完成狀態

使用者可以切換每筆工作的完成狀態。

已完成項目應具有清楚的視覺差異，例如：

* 刪除線
* 字體顏色變淡
* 背景樣式改變

完成狀態變更後，應立即更新 `localStorage`。

### 6.4 刪除待辦事項

每筆項目應提供刪除按鈕。

刪除後：

* 項目立即從畫面移除
* `localStorage` 內容同步更新
* 統計數量同步更新

### 6.5 localStorage 儲存

待辦資料至少應包含：

* 唯一識別值
* 工作內容
* 完成狀態

建議資料格式：

```json
[
  {
    "id": 1,
    "text": "整理今日工作",
    "completed": false
  }
]
```

實際欄位名稱可以調整，但結構必須清楚且可維護。

### 6.6 工作統計

頁面應顯示：

* 全部項目數量
* 未完成項目數量
* 已完成項目數量

新增、刪除或切換完成狀態後，統計必須立即更新。

### 6.7 空白狀態

當目前沒有任何工作項目時，畫面應顯示清楚的提示，例如：

> 目前沒有工作項目。

新增第一筆項目後，空白提示應自動消失。

## 7. 預留給 OpenCode 的功能

以下功能在 Claude Code 階段不得實作。

### 7.1 工作篩選

後續需要加入三種篩選模式：

* 全部
* 待完成
* 已完成

### 7.2 清除已完成項目

後續需要加入「清除已完成」按鈕，一次刪除所有完成項目。

### 7.3 篩選狀態樣式

後續需要讓目前選取的篩選模式具有清楚的視覺狀態。

Claude Code 可以在版面中保留適合放置上述功能的位置，但不得加入可操作的篩選或清除功能。

## 8. 介面需求

頁面應包含以下區域：

### 8.1 標題區

顯示：

* 專案名稱 `Focus Board`
* 一句簡短說明

例如：

> 整理今天需要完成的工作。

### 8.2 新增區

包含：

* 工作內容輸入欄位
* 新增按鈕

### 8.3 統計區

顯示全部、未完成與已完成數量。

### 8.4 工作清單區

顯示所有工作項目。

### 8.5 預留控制區

在統計區與工作清單附近預留一個區域，供後續加入：

* 全部／待完成／已完成篩選按鈕
* 清除已完成按鈕

Claude Code 階段不需要顯示尚未實作的假按鈕。

---

## 9. 視覺風格

整體介面應符合以下方向：

* 簡潔
* 容易閱讀
* 適合桌面瀏覽器
* 不使用過度複雜的動畫
* 不模仿特定商業產品
* 保持足夠的留白
* 按鈕與輸入欄位具有一致風格
* 已完成項目與未完成項目容易區分

畫面不需要達到商業產品等級，但不能只有未加樣式的原生 HTML。

---

## 10. 響應式需求

頁面主要針對桌面瀏覽器設計，但在較窄的視窗中也應維持基本可用性。

最低要求：

* 內容不應超出畫面寬度
* 輸入欄位與按鈕不應互相重疊
* 工作文字過長時可以換行
* 統計區在窄螢幕下可以換行排列

---

## 11. 無障礙與易用性需求

* 所有按鈕應有清楚的文字或可理解標籤。
* 輸入欄位應有對應的 label 或 `aria-label`。
* 使用鍵盤可以操作輸入欄位與按鈕。
* 不得只透過顏色傳達完成狀態。
* 刪除按鈕應明確標示其用途。
* 按鈕應有 hover 與 focus 狀態。

---

## 12. 錯誤處理

系統至少需要處理以下情況：

### 12.1 空白輸入

不得建立空白項目。

### 12.2 localStorage 沒有資料

首次開啟頁面時應正常顯示空白狀態，不得發生錯誤。

### 12.3 localStorage 資料損壞

若讀取到無法解析的資料：

* 頁面不得停止運作
* 可以將清單重設為空陣列
* 可在 Console 顯示警告
* 不需要在畫面顯示複雜錯誤訊息

### 12.4 工作內容過長

過長文字應正常換行，不得破壞版面。

* 專案簡介

## 15. 程式碼品質要求

* 使用容易理解的函式與變數名稱。
* 避免將所有邏輯寫在單一函式中。
* 資料操作、畫面更新與儲存邏輯應適度拆分。
* 避免不必要的全域變數。
* 不要使用難以理解的技巧壓縮程式碼。
* 不需要過度抽象化。
* 可加入必要註解，但不要替每一行程式碼加入註解。
* 不保留未使用的程式碼。
* 不加入與需求無關的功能。

## 16. 驗收條件

Claude Code 完成後，必須符合以下條件。

### 功能驗收

* 可以新增一般文字工作項目。
* 空白內容不會被新增。
* 按下 Enter 可以新增項目。
* 新增後輸入欄位會清空。
* 可以將項目標記為完成。
* 可以將完成項目恢復為未完成。
* 已完成項目具有清楚的視覺差異。
* 可以刪除單一項目。
* 重新整理頁面後資料仍存在。
* 重新開啟瀏覽器後資料仍存在。
* 全部、未完成與已完成數量正確。
* 沒有項目時會顯示空白提示。
* 新增、刪除與切換狀態後統計會立即更新。

### 結構驗收

* 存在 `src/index.html`。
* 存在 `src/style.css`。
* 存在 `src/app.js`。
* 存在 `README.md`。
* 存在 `CLAUDE.md`。
* 存在 `docs/PRD.md`。
* 不存在 `AGENTS.md`。
* 不存在 package manager 設定檔。
* 不存在外部套件依賴。

### 預留功能驗收

Claude Code 完成的版本不得包含：

* 可操作的工作篩選功能
* 清除所有已完成項目的功能
* 已實作的篩選狀態
* `AGENTS.md`

## 17. 手動測試流程

完成後依序執行以下測試：

1. 開啟頁面，確認顯示空白狀態。
2. 輸入「整理今日工作」並按下新增。
3. 確認項目出現在清單中。
4. 輸入「撰寫會議紀錄」並按 Enter。
5. 確認總數為 2，未完成數為 2，完成數為 0。
6. 將第一筆項目標記為完成。
7. 確認總數為 2，未完成數為 1，完成數為 1。
8. 重新整理頁面。
9. 確認兩筆資料與完成狀態仍存在。
10. 將第一筆項目恢復為未完成。
11. 刪除第二筆項目。
12. 確認總數為 1，未完成數為 1，完成數為 0。
13. 刪除最後一筆項目。
14. 確認重新顯示空白狀態。
15. 嘗試輸入只有空格的內容。
16. 確認不會建立新項目。
17. 輸入一段較長文字，確認畫面不會溢出。
18. 使用 Tab 鍵確認輸入欄位與按鈕可以取得焦點。

---

## 18. 完成定義

當以下條件全部滿足時，Claude Code 階段才算完成：

* 所有 Claude Code 階段功能均已實作。
* 所有驗收條件均已通過。
* README 已更新。
* CLAUDE.md 已建立。
* 程式碼可以直接在瀏覽器中執行。
* 沒有加入需求以外的框架或套件。
* 沒有實作預留給 OpenCode 的功能。
* 最終回覆列出：

  * 新增或修改的檔案
  * 已完成的功能
  * 手動測試結果
  * 尚未完成並預留給 OpenCode 的功能
